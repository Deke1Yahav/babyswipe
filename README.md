# בייביסוויפ

אב-טיפוס לאפליקציה לאיתור בייביסיטר זמינים במהירות, בסגנון טינדר.

## מה יש באב-טיפוס

- **החלקה:** גוררים כרטיס ימינה כדי לשמור ושמאלה כדי לדלג. יש גם כפתורים, חצים במקלדת וביטול פעולה אחרונה.
- **סינון:** מרחק מקסימלי, מחיר מקסימלי לשעה, "פנויים עכשיו בלבד", ומיון לפי קרבה, מחיר או דירוג.
- **מפה:** מסמנים עם שם ומחיר, עיגול של טווח החיפוש סביב המיקום שלך, הזזה וזום, וקישור לניווט ב-Google Maps.
- **מיקום:** "מצא אותי" משתמש ב-GPS של הדפדפן. אם אין גישה, אפשר לקבוע מיקום בהקשה על המפה.
- **שמורים:** רשימת הבייביסיטרים ששמרת, עם מספר טלפון וכפתור העתקה.

## הרצה

קובץ אחד, בלי התקנות: פותחים את `index.html` בדפדפן.
GPS בדפדפן עובד רק מ-`https` או מ-`localhost`, למשל: `python3 -m http.server` ואז http://localhost:8000.

## מגבלות

- כל הבייביסיטרים הם **נתוני דוגמה** סביב מרכז תל אביב, והטלפונים פיקטיביים.
- המפה מצוירת באופן כללי ואינה מפה אמיתית.
- ההחלטות והסינון נשמרים רק בדפדפן (localStorage).

## השלבים הבאים

- אפליקציה אמיתית (React Native או Flutter) עם GPS ו-Google Maps.
- שרת והרשמה של בייביסיטרים, זמינות בזמן אמת.
- התאמה הדדית וצ'אט, אימות זהות וביקורות.
